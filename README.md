# TOKYO+

## ビジョン

**「都市と人との関係そのものを変えるプラットフォーム」**

TOKYO+は、東京都オープンデータとAIを活用し、**「今、自分はどう行動すべきか」という判断**を提供する都市AIを目指します。

このアプローチにより、利用者のニーズに最適な『行動指針』を届け、**都市と人との関係そのものを変える**ことを目指します。

**現在の課題解決に加え、時代の変化に応じた柔軟な進化**を可能にし、**「検索する都市」から「判断してくれる都市」への転換**を実現します。

## Concept

『情報を集めるAI』ではなく、『行動を決めるAI』を目指します。

## コアバリュー

1. **データの横断的統合**：東京都オープンデータと外部APIを連携し、複数の情報を統合分析
   （例: 天気×交通×工事情報の連携で最適ルートを提案）

2. **AIによるスマート判断**：状況に応じた優先順位の自動判断と、その理由の説明
   （例: 災害時における避難ルートの優先順位と説明文）

3. **ユーザー中心の行動提案**：「情報を表示する」ではなく、必要な「行動指針」のみを届ける
   （例: 100件の情報→3件の判断へ要約）

## MVP（最小構成）

### 1. 今日のアドバイス
- 毎朝、オープンデータをもとに「その日に必要な判断」を通知
  （例: 水筒持参・10分早く出発・折りたたみ傘の推奨）

### 2. エージェント機能の実装
- ユーザータグと都市データをもとに、**自動的な通知・判断を提供**

※避難先の選定を行う避難アシストは将来構想として保持する。MVPでは、地震情報が基準を満たした場合の「公式情報を確認する」注意喚起のみを扱う。

## 最終目標

**「検索する都市から、判断してくれる都市へ」**

TOKYO+は、都市データを可視化するのではなく、**「人を理解するAI」への進化**を目指します。

このプラットフォームは、個人・組織のニーズに応じた**カスタムモジュール**を追加可能で、**全国・海外への展開**を視野に入れた拡張性を備えます。

## 利用するオープンデータ

MVPで実取得・検証済みの利用データは、[基本設計書のシナリオ・データソース台帳](./basic_design.md#64-mvp確定データソースとシナリオパック2026-08-08検証)に記載する。

- 気象庁の東京地方予報JSON
- 環境省のWBGT予測API
- 中央区の公衆トイレ一覧（位置情報の補助データ）
- 東京都の公衆無線LANアクセスポイント一覧
- 23区内の都道路上工事情報
- 気象庁の地震情報一覧JSON（公式情報確認の注意喚起に限定）

交通、混雑、PM2.5、避難所等は、鮮度・利用条件・実取得を確認したうえで追加する。

# TOKYO+が新しい理由

| 従来の都市サービス | TOKYO+ |
|-------------------|---------|
| 情報を検索する | AIが判断する |
| サービスごとに利用 | 都市データを横断利用 |
| 情報を表示する | 行動を提案する |
| 利用者が判断する | AIが優先順位を付ける |

---

# Goal

TOKYO+の最終目標は、都市データを可視化することではありません。

都市そのものを、一人ひとりに寄り添うAIへ進化させることです。

**検索する都市から、判断してくれる都市へ。**

TOKYO+は、その最初の一歩を目指します.
