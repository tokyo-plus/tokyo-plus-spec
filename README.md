# TOKYO+

## Why TOKYO+

都市は毎日、天気・交通・災害・イベント・混雑・工事など、膨大な情報を発信しています。

しかし現在は、利用者が複数のアプリを開き、それらの情報を集め、自分で状況を整理し、行動を判断しなければなりません。

人が本当に欲しいのは、より多くの情報ではありません。

**「今、自分はどう行動すればいいのか」という、たった一つの判断です。**

TOKYO+は、東京都オープンデータとAIを活用し、都市の情報を一人ひとりに最適な『判断』へ変換することを目指します.

## Vision

> **人が都市を理解するのではなく、都市が人を理解する。**

TOKYO+は東京都オープンデータと外部データをAIが横断的に理解し、その人に必要な『判断』だけを届ける都市AIです。

私たちが目指すのは「都市のダッシュボード」ではありません。

**都市の判断レイヤー（Urban Decision Layer）**です。

## Concept

『情報を集めるAI』ではなく、『行動を決めるAI』を目指します。

## Core Value

1. 都市データを統合する
2. AIが優先順位を判断する
3. ユーザーには行動だけを届ける

例: 100件の都市情報 → AIが3件の判断へ要約

# TOKYO+

天気、交通、災害、イベント、混雑、工事、防犯、熱中症…。

**『今、自分はどう行動すればいいのか』という判断です。**

TOKYO+は、東京都オープンデータと外部データをAIが横断的に統合し、一人ひとりに必要な『判断』だけを届ける都市AIです。

---

# Why

現在の都市サービスは『検索型』です。

利用者は必要な情報を得るために複数のアプリを開き、自分で状況を整理し、判断しなければなりません。

- 天気アプリ
- Google Maps
- 乗換案内
- 防災アプリ
- イベント情報

情報は増え続けていますが、人が判断する負担は減っていません。

TOKYO+は、この『判断コスト』をAIでなくすことを目指します。

---

# Vision

TOKYO+が目指すのは都市のダッシュボードではありません。

**都市の判断レイヤー（Urban Decision Layer）**です。

東京都オープンデータをAIが理解し、ユーザーには『情報』ではなく『行動』を届けます。

```
100件の都市情報
        ↓
      TOKYO+
        ↓
 あなたへの3つの判断
```

---

# Core Value

TOKYO+は3つのステップで判断を生成します。

1. 都市データを横断的に収集する
2. AIが状況と優先順位を判断する
3. 利用者には行動だけを届ける

AIは判断理由も説明するため、ブラックボックスになりません。

---

# MVP

## 1. 今日のアドバイス

毎朝、東京都オープンデータをもとに、その日に知っておくべきことだけを通知します。

### 利用データ
- WBGT
- 天気
- 公共交通
- イベント
- 混雑
- 工事情報

### AIの判断例
- 水筒を持って行きましょう
- 10分早く出発しましょう
- 折りたたみ傘がおすすめです

---

## 2. 避難アシスト

災害発生時に現在地と都市データから最適な避難行動を提案します。

### 利用データ
- 避難所
- ハザードマップ
- 河川情報
- AED
- 公共交通

### AIの判断例
- 最も安全な避難所はこちらです
- 河川増水のため別ルートを推奨します
- Google Mapsで避難ルートを開きます
